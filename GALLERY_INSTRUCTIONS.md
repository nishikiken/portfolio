# Инструкция по добавлению работ в галерею

Галерея работает полностью статически - без сервера и базы данных!

## Как добавить новую работу (ПРОСТОЙ СПОСОБ):

1. **Добавь изображение в папку `uploads/`**
   - Положи файл картинки в папку `portfolio/uploads/`
   - Например: `my-awesome-work.jpg`

2. **Запусти батник `update_gallery.bat`**
   - Он автоматически:
     - Сгенерирует `gallery.json` из всех файлов в `uploads/`
     - Скопирует всё в GitHub репозиторий
     - Закоммитит и запушит изменения

3. **Готово!** Через 1-2 минуты изменения появятся на сайте

## Как это работает:

- Скрипт `generate_gallery.py` сканирует папку `uploads/`
- Находит все изображения (jpg, png, gif, webp)
- Автоматически создает названия из имен файлов
- Генерирует `gallery.json`

## Примеры названий:

- `my-work.jpg` → "My Work"
- `cool_design.png` → "Cool Design"  
- `project-2024.jpg` → "Project 2024"

## Поддерживаемые форматы:
- JPG/JPEG
- PNG
- GIF
- WebP
- BMP

## Советы:
- Используй понятные имена файлов - они станут названиями работ
- Оптимизируй изображения перед загрузкой (до 2MB)
- Используй латиницу в именах файлов
- Вместо пробелов используй дефис `-` или подчеркивание `_`

## Ручное редактирование (опционально):

Если хочешь изменить названия работ, отредактируй `gallery.json` вручную:

```json
[
  {
    "filename": "my-work.jpg",
    "title": "Моё крутое название"
  }
]
```
