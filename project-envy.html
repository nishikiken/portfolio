# Envy — macOS Dynamic Island для Windows

Envy — приложение, которое переносит эстетику macOS на Windows, добавляя интерактивную шторку с управлением музыкой, быстрым доступом к функциям и гибкой кастомизацией интерфейса.

  • Музыкальный плеер — управление воспроизведением, паузой, переключением и перемоткой треков прямо из шторки.
  • Drop & Shelf — временная полка для файлов, к которым нужен быстрый доступ без поиска по папкам.
  • Переводчик new! — мгновенный перевод текста прямо из шторки, захват и распознавание выделенной области на экране (OCR), а также удобный двусторонний переводчик в настройках с автоопределением языка.
  • Кастомизация — настройка цветов логотипа и интерфейса, а также интенсивности свечения обложки альбома.
  • Тексты песен — отображение текста прямо в шторке. Функция находится в бета-версии и может работать нестабильно: возможны задержки и рассинхронизация. Из-за этого её использование пока не рекомендуется.
  • Встроенный мини-браузер — доступ к SoundCloud и YouTube для прослушивания музыки прямо внутри приложения. Для SoundCloud предусмотрен обход ограничения, из-за которого может прерываться запись через NVIDIA ShadowPlay.
  • Отдельное окно браузера — возможность открепить браузер от настроек и использовать его в самостоятельном окне.
  • Скругление углов экрана — визуальный эффект в стиле MacBook с выбором двух или четырёх скруглённых углов.

Envy сочетает визуальный стиль macOS, музыкальные инструменты и дополнительные функции Windows в одном лёгком приложении, оптимизированном для минимальной нагрузки на систему.
