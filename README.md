# Portfolio Website с галереей работ

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install Flask Flask-CORS Werkzeug
```

### 2. Запуск сервера
```bash
python upload_server.py
```

Сервер запустится на `http://localhost:5000`

### 3. Открытие сайта
Откройте `portfolio.html` в браузере

## Использование

### Просмотр галереи
1. Откройте сайт в браузере
2. Перейдите в раздел "Портфолио"
3. Нажмите на карточку "📸 Галерея работ"
4. Откроется модальное окно с галереей
5. Кликните на любое изображение для полноэкранного просмотра

### Навигация по галерее
- **Стрелки влево/вправо** - переключение между изображениями
- **Кнопки ‹ ›** - навигация мышью
- **Свайпы** - на мобильных устройствах
- **Escape** - закрыть просмотр
- **Счетчик** - показывает текущее изображение (например: 3 / 10)

### Добавление изображений (Админ-панель)

#### Способ 1: Через секретную комбинацию (на основном сайте)
1. Нажмите `Ctrl + Shift + E` на клавиатуре
2. Появится кнопка "🔒 Режим редактирования"
3. Нажмите на неё
4. Откройте галерею - появится форма загрузки

#### Способ 2: Через админ-панель (рекомендуется)
1. Откройте `admin.html` в браузере
2. Выберите изображение
3. Добавьте название (опционально)
4. Нажмите "Загрузить в галерею"
5. Можете сразу удалять ненужные изображения

## Структура

- `portfolio.html` - главная страница сайта
- `admin.html` - админ-панель для управления галереей
- `upload_server.py` - backend сервер для загрузки файлов
- `uploads/` - папка с загруженными изображениями (создается автоматически)
- `gallery_data.json` - данные о галерее (создается автоматически)
- `фон.png`, `фон2.png` - фоновые изображения

## Особенности

- Загрузка изображений до 16MB
- Поддержка форматов: PNG, JPG, JPEG, GIF, WEBP
- Автоматическое сохранение данных
- Полноэкранный просмотр с анимациями
- Навигация стрелками и свайпами
- Счетчик изображений
- Скрытый режим редактирования (Ctrl+Shift+E)
- Отдельная админ-панель для удобного управления
- Адаптивный дизайн
- Плавная смена фона при скролле
